## 移植驗收規則
1. 不直接把舊 HTML 中的舊登入／外掛邏輯投入新站。
2. 每一個來源頁面都要建立 source title、來源位置、目標一級／二級選單、目標 URL ID、素材清單、移植狀態。
3. 原始文字、圖片、連結與附件先保留；新功能由新 CMS/API 實作。
4. 任何不明確的歸屬先標記待確認，不可自行刪除。
5. 在建立完整 37 筆逐頁對照表並逐頁核對前，不宣告內容移植完成。
