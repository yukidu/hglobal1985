## 移植驗收規則
1. 建立每頁的原始 WP ID、原始標題、原網址、原始正文、圖片位置／來源 URL、表格、影音連結與附件清單。
2. 保留每筆原始正文的唯讀初始版本，編輯後可追溯；不得只移植標題或空白模板。
3. 圖片／附件若原檔不存在，標記「待補素材」，不可假裝已移植。
4. 舊登入／外掛頁映射到新系統，不執行舊外掛短代碼或未知 WordPress 程式。
5. 新增的領導人、公告、課表、相簿、活動與場地等，不算入原始 37 頁。
6. 健管45、健康媒體資源等 V10 標註「待使用者最後確認」的分類，在正式移植前不得自行定案。
