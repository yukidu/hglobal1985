# H-Global 舊站來源檔實測盤點（2026-10-21）

## 來源
已實際解析使用者提供的 `HGlobal_舊網站實際內容_安全預覽版(1).html`，而非只依 V10 交接包推測。此來源為 WordPress CSV 的安全離線還原，不等於完整 WordPress 媒體、外掛資料或會員資料備份。

## 量化盤點
- `section.page`：**37** 筆；與 V10 的 25 個內容頁＋12 個功能頁一致。
- `figure` 圖片位置：**309** 個。它們是版位／來源線索，**不是 309 個已取得的圖片原檔**。
- `table`：**5** 張表格，必須保留欄列及內容。
- `section.page[id]` 形如 `p-468`，原 WP ID 可由此提取。
- 每頁 `data-page-title`、`.article`、`.links a` 可作為原標題、正文快照及舊網址的資料來源。
- 舊外掛短代碼（例如 `[dlm_no_access]`、`[aiovg_search]`、`[mine_video]`）**只能留存原文，不可當成可執行程式匯入**。

## 安全匯入門檻
1. 對每一頁產生固定內部主鍵、原 WP ID、原標題、原網址、原始正文唯讀快照及可編輯新版草稿。
2. 清理來源 HTML：拒絕 `script`、事件處理屬性、`javascript:` URL、`iframe` 自動執行；使用嚴格白名單。原始快照只供後台稽核，不直接以不受信任 HTML 注入前台。
3. 309 個圖片位置逐一建立資產待補清單；未取得原檔時不得顯示為「已移植」。
4. 保留 5 張表格內容，包含原始欄列順序。
5. 系統功能頁改為 Starry ID／H-Global 對應功能，不啟動舊 PHP 外掛及短代碼。
6. 內容頁路徑採 `/{publicNumericID}/{slug}`；保留 `?page_id=...` 301 對照。不得使用 `/p/`。
7. 權限必須在伺服器端驗證；不可讓未授權者藉由頁面 API 或媒體直連取得會員內容。
8. 「健管45」「健康媒體資源」仍保留待分類狀態；不擅自定案。
9. 未經驗收的匯入不得寫入 Production D1；先在獨立 Preview D1 驗證。
