# H-Global 功能驗收範圍

## 固定一級選單順序
首頁、最新消息、活動報名、寰宇大學、活動花絮、場地租借、關於寰宇。

## 本批次驗收
- 手機優先的翡翠綠 × 香檳金 UI。
- 七個一級選單與各自的第二層示意項目。
- 第二層選單預設展開；按鈕緊密排列、自動換行。
- 固定五鍵工具列：上一頁、分享、回頂端、訂閱、下一頁。
- 上下頁切換實際內容頁，不只移動選單狀態。
- 工具列可縮小為右下角半透明 H 標記。
- 分享優先呼叫裝置原生分享 API。
- 不可訂閱的頁面將訂閱鍵停用。
- 測試環境顯示醒目提示，搜尋引擎不索引。
- 所有登入、儲存、報名、預訂等未接後端功能須明確標示示意。
