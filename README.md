# H-Global 寰宇全球

正式程式碼儲存庫。GitHub `main` 為唯一正式基準。

## 開發流程
1. 建立功能分支
2. Pull Request
3. Cloudflare Pages Preview
4. 測試與驗收
5. Squash merge 到 `main`
6. 正式部署（需確認驗收通過）

## 原則
- 先建立測試版，不直接把未驗收版本發布到正式網域。
- H-Global 的應用資料庫、物件儲存與 API 必須獨立。
- Starry ID 僅透過核准的 API 提供身分資料；不得直接共用其應用資料庫。
- 保留 V10 交接包中所有已確認功能及刪除決策。
- V11.3「翡翠綠 × 香檳金」為核准視覺基準。
- 不在此倉庫提交任何秘密、API token 或正式會員資料。

## 狀態
目前為初始基準建立階段。完整功能將分階段實作與驗收。
